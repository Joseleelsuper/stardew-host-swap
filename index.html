How to install the modified save:

  1. Download the ZIP file using the button above
  2. Extract the ZIP file on your computer
  3. Copy all files from the "modified_files" folder to your Stardew Valley save folder (see the Stardew Valley Wiki for locations)
  4. If something goes wrong, you can restore the original files from the "backup_files" folder

Known Issues

  • Different people may see different amounts of things donated to the community center. Have the host place donations to be safe.
  • The TV shows different luck levels for different players
  • The software is so good that if you try to upload the modified ZIP file, it will detect the host as the old host and not the current host. This do not happen with the legacy paste method and do not affect the ingame host change.
  • Some Farmers will be not be able to become host of the farm. This is caused by tags not in the Farmer information.

Issues Fixed

Issues fixed (18/07/2025):

  • The level of the principal Farm house may be reset to 1 when the new host is added (This happened because it was necesary to change in the XML some information from the old host to the new host)
  • New host may get outdated mail (Thanks to the transfer of important events to the new host from the old host, you should no longer receive emails. If this error still occurs, you can report it in an issue)
  • Host shown on load screen stays original host when first loading

Issues fixed (9/23/2018):

  • Willy's shop may act like it was never unlocked

Issues fixed (7/31/2018):

  • New host repeats host-only events, like picking mushrooms or bats
  • Messes up which house is upgraded
  • Community center and Jojamart events may act as if they didn't happen
  • Community improvements like minecarts may stop working
